Method & caveats.
  • Ranking: hugovk/top-pypi-packages 30-day downloads, snapshot 2026-07-01.
  • “Native” = latest release ships a platform-specific wheel, or its sdist builds compiled code. Optional-accelerator packages that also publish a pure py3-none-any wheel count as native (9 of the top-100’s 25).
  • Dependency closure: requires_dist of each latest release, markers evaluated for CPython 3.12 / linux / x86_64, no extras — extras slightly undercount, version-range back-solving isn’t modeled.
  • Flame attribution: each (package, native dep) pair follows one shortest path; packages reaching a dep by several routes are counted on the shortest one only.
  • Small frames fold into “(other)”; the full unpruned tree is in data/flame_full.json.
